# 🔒 PDPA and Privacy

ระบบเก็บข้อมูลส่วนบุคคลจำนวนมาก (ชื่อ, เบอร์, ที่อยู่, เงินเดือน, ที่ทำงาน) → **ต้องออกแบบตั้งแต่ต้น ไม่ใช่ตามแก้ทีหลัง**

## หลักการ
1. **Consent ชัดเจน** ตอน claim โปรไฟล์ — แจ้งวัตถุประสงค์ ระยะเวลาเก็บ และผู้ที่เข้าถึงได้
2. **Privacy รายฟิลด์** — ศิษย์เก่าเลือกได้ว่าฟิลด์ไหน public / เฉพาะสมาชิก / ส่วนตัว
3. **บังคับ login ก่อนดูข้อมูลติดต่อ** (ลอกจาก Entaneer — [[Benchmark - Faculty Level]])
4. **Data minimization** — เก็บเท่าที่ใช้จริง เงินเดือนเก็บเป็นช่วง ไม่เก็บตัวเลขจริง
5. **Audit log** — บันทึกว่าใครดูข้อมูลใคร

## ประเด็นเฉพาะของโปรเจ็คนี้
- **ข้อมูลตั้งต้นจากทะเบียน** — ใช้ฐานทางกฎหมายใด? (สัญญา / ประโยชน์โดยชอบด้วยกฎหมาย / ความยินยอม) ต้องปรึกษาผู้รับผิดชอบ PDPA ของมหาวิทยาลัย
- **ข้อมูลของคนที่ยังไม่ claim** — มีอยู่ในระบบแต่ยังไม่ยินยอม → **ห้ามแสดงผลสาธารณะ**
- **ข้อมูลเงินเดือน** ใช้เพื่อ analytics → ต้อง anonymize/aggregate เท่านั้น
- **แบบสอบถามเพื่อวิจัย** → อาจต้องผ่าน IRB → [[Open Questions]]
