# Project Charter

## ชื่อโปรเจ็ค
ระบบสารสนเทศศิษย์เก่า คณะวิศวกรรมศาสตร์ มหาวิทยาลัยกาฬสินธุ์
(working dir: `D:\work\KSU\ENG_APP\Alumi_EN`)

## ปัญหา (Problem statement)
> ยืนยันกับผู้เกี่ยวข้องก่อน — ข้อความด้านล่างเป็นสมมติฐานจาก research

- ระบบศิษย์เก่าระดับมหาวิทยาลัย ([[Benchmark - KSU]]) เป็นเว็บประชาสัมพันธ์เป็นหลัก ยังไม่มี directory ที่ค้นหาได้
- ลิงก์ "ระบบบริหารงานศิษย์เก่า" เดิม (`alumni.ksuitcs.com`) **resolve DNS ไม่ได้** ณ 2026-09-23
- ข้อมูลศิษย์เก่ากระจัดกระจาย ติดตามภาวะการมีงานทำเพื่อรายงาน QA ได้ยาก
- ไม่มีช่องทางเชื่อมรุ่นพี่–รุ่นน้อง (ฝึกงาน/สมัครงาน/mentor)

## เป้าหมาย (Goals)
1. มีฐานข้อมูลศิษย์เก่าคณะวิศวะที่ **ค้นหาได้หลายมิติ** และข้อมูลไม่ตาย
2. เชื่อมข้อมูล **ภาวะการมีงานทำ** เข้ากับรายงานประกันคุณภาพหลักสูตร
3. สร้างช่องทาง engagement ที่ศิษย์เก่ากลับมาใช้จริง (job board / ข่าว / กิจกรรม)
4. ผลิต **ผลงานตีพิมพ์** จากส่วน contribution เชิงเทคนิค → [[Research Gap]]

## ขอบเขต (Scope)
### In scope
- เว็บแอปพลิเคชันระดับ**คณะ** (ไม่ใช่ทั้งมหาวิทยาลัย)
- โมดูลตาม [[Requirements]]

### Out of scope (ชั่วคราว)
- ระบบบัญชี/การเงินของสมาคมเต็มรูปแบบ
- แอป native (พิจารณา PWA แทน)

## ผู้มีส่วนได้ส่วนเสีย
| กลุ่ม | ความสนใจหลัก |
|---|---|
| ศิษย์เก่า | ค้นหาเพื่อน, งาน, ข่าวกิจกรรม, สิทธิประโยชน์ |
| คณะ/หลักสูตร | ข้อมูล QA, ภาวะการมีงานทำ, feedback ปรับหลักสูตร |
| นักศึกษาปัจจุบัน | ฝึกงาน, mentor, เส้นทางอาชีพ |
| สมาคมศิษย์เก่า | สมาชิก, กิจกรรมคืนเหย้า, ระดมทุน |
| งานทะเบียน/IT มหาวิทยาลัย | เจ้าของข้อมูลตั้งต้น (CONGRATE / ทะเบียน) |

## ความเสี่ยงหลัก
- **ข้อมูลตาย** — ศิษย์เก่ากรอกครั้งเดียวไม่กลับมา (ดู [[Engagement Strategy]])
- **PDPA** — เปิด directory สาธารณะมีความเสี่ยง (ดู [[PDPA and Privacy]])
- **การเข้าถึงข้อมูลตั้งต้น** — ต้องเจรจาขอข้อมูลจากทะเบียน/CONGRATE
