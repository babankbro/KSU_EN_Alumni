# 🎓 Benchmark — ระดับคณะวิศวกรรมศาสตร์

ใกล้เคียง use case ของเรามากที่สุด

## สมาคมศิษย์เก่าคณะวิศวกรรมศาสตร์ ม.นเรศวร
`engalumni.nu.ac.th` — ใกล้เคียง scope ที่สุด

- **เมนู:** หน้าแรก / สมาคม (ประวัติ, โครงสร้าง, ศิษย์เก่าดีเด่น) / กิจกรรม / ทำเนียบรุ่น / ข่าวสาร-รับสมัครงาน / Gallery
- **โมดูล:** สมัครสมาชิก (สามัญ = ป.ตรี/โท คณะวิศวะ), login, โปรไฟล์ส่วนตัว, **ประวัติการชำระเงินค่าสมาชิก**, ระบบเสนอชื่อศิษย์เก่าดีเด่น
- ทำเนียบรุ่นแสดงสถิติ: **31 ปี / 8 สาขา / 2,824 คน**
- ชำระเงิน: โอนบัญชีธนาคาร + แจ้งผ่าน **LINE OA** (ยังไม่เป็น payment gateway จริง)

> 💡 สถิติหน้าแรก (ปี/สาขา/จำนวนคน) เป็น social proof ที่ทำง่ายและได้ผล — ควรลอก

## ฐานข้อมูลศิษย์เก่าคณะวิศวะ มช. (Entaneer)
`entaneer.com` — **สมบูรณ์ที่สุดที่เจอ (15,537 สมาชิก)**

- **Faceted search หลายมิติ** ← จุดที่ควรลอกที่สุด
  - ตามเกียร์/รุ่น (57 รุ่น)
  - ตามภาควิชา (9 สาขา)
  - ตามจังหวัด (+ ต่างประเทศ)
  - ตามองค์กร/บริษัท
  - ตามตำแหน่งงาน, กลุ่มอาชีพ, ทักษะวิชาชีพ
- โปรไฟล์แสดง **"อัปเดตข้อมูลเมื่อ"** — pattern จัดการปัญหาข้อมูลเก่าที่ดีมาก
- มี Blogs/คลังความรู้, ปฏิทินกิจกรรม, ประกาศงาน+ฝึกงาน
- **บังคับ login** เพื่อดูข้อมูลบางส่วน → ป้องกัน PDPA/scraping (ดู [[PDPA and Privacy]])
