# 📖 งานวิจัยไทยที่เกี่ยวข้อง

มีสายงานวิจัย **"การพัฒนาระบบฐานข้อมูลศิษย์เก่า"** ตีพิมพ์ในวารสาร TCI ค่อนข้างเยอะ — เป็น niche ที่ตีพิมพ์ได้จริง

## รายการที่พบ
| งาน | แหล่ง |
|---|---|
| การพัฒนาระบบฐานข้อมูลศิษย์เก่า คณะวิทยาศาสตร์และเทคโนโลยี | วิทยานิพนธ์ ม.ศิลปากร (ithesis-ir.su.ac.th) |
| การพัฒนาระบบฐานข้อมูลศิษย์เก่า คณะวิทยาการจัดการ ม.ราชภัฏธนบุรี | วารสารวิทยาการจัดการ มรภ.ธนบุรี (TCI) |
| การพัฒนาระบบฐานข้อมูลศิษย์เก่า วิทยาลัยธาตุพนม ม.นครพนม | วารสารนวัตกรรมการจัดการและบริหารธุรกิจ (TCI) |
| การพัฒนาเว็บไซต์ศิษย์เก่า ม.ราชภัฏบุรีรัมย์ | วารสารการจัดการเทคโนโลยีสารสนเทศและนวัตกรรม |
| ระบบจัดการฐานข้อมูลงานวิจัยนักศึกษา ป.ตรี ม.ราชภัฏเลย | so09.tci-thaijo.org |

## Pattern ของงานวิจัยกลุ่มนี้
- **Tech:** web application (PHP/MySQL + Bootstrap) เป็นส่วนใหญ่
- **Methodology:** SDLC / ADDIE
- **การประเมิน:** ประสิทธิภาพระบบ + **ความพึงพอใจผู้ใช้ (5-point Likert)**; บางงานใช้ **TAM** (Technology Acceptance Model)
- **กลุ่มตัวอย่าง:** อาจารย์ เจ้าหน้าที่ นักศึกษา ศิษย์เก่า

## ข้อวิจารณ์
งานส่วนใหญ่เป็น **system development report** มากกว่างานวิจัยที่มี novelty เชิงเทคนิค
ผลลัพธ์จบที่ "ความพึงพอใจอยู่ในระดับมาก" ซึ่งเป็น outcome ที่คาดเดาได้
