## จัดลำดับฟีเจอร์

### 🟢 Core — เจอเกือบทุกที่ (ต้องมี)
1. ข่าวสาร/ประชาสัมพันธ์ + ปฏิทินกิจกรรม
2. สมัครสมาชิก + login + โปรไฟล์แก้ไขเองได้
3. ทำเนียบรุ่น / alumni directory
4. Gallery ภาพกิจกรรม
5. ศิษย์เก่าดีเด่น (+ ระบบเสนอชื่อ)
6. ข้อมูลสมาคม/โครงสร้างกรรมการ
7. ติดต่อ + Social (Facebook / **LINE OA** เป็นช่องทางหลักจริงของคนไทย)

### 🟡 Differentiator — มีน้อย = โอกาส
8. **Faceted search หลายมิติ** (รุ่น/สาขา/จังหวัด/บริษัท/ตำแหน่ง/ทักษะ) — มีแค่ Entaneer
9. Job board ฝึกงาน+สมัครงาน จากศิษย์เก่าสู่รุ่นน้อง
10. ระบบชำระค่าสมาชิก/บริจาค + ประวัติการชำระ
11. เชื่อมภาวะการมีงานทำ + ความพึงพอใจผู้ใช้บัณฑิต → รายงาน QA อัตโนมัติ
12. ของที่ระลึก/จองเสื้อคืนเหย้า (KSU ทำอยู่แต่ manual)

### 🔵 Blue ocean — แทบไม่มีใครทำ
- Mentorship matching รุ่นพี่–รุ่นน้อง
- Dashboard วิเคราะห์เส้นทางอาชีพ/เงินเดือนตามหลักสูตร → ป้อนกลับสู่การปรับปรุงหลักสูตร
- Mobile-first / PWA + บัตรศิษย์เก่าดิจิทัล (QR)
- SSO ผ่าน TUC Digital ID
