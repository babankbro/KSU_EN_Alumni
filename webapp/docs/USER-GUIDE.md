# คู่มือผู้ใช้ — เว็บไซต์ศิษย์เก่าคณะวิศวกรรมศาสตร์และเทคโนโลยีอุตสาหกรรม ม.กาฬสินธุ์

สำหรับศิษย์เก่าและนักศึกษาปัจจุบัน (NFR-MNT-01)

## 1. เริ่มต้น

### ศิษย์เก่า — สมัครสมาชิก / Claim โปรไฟล์ (เมนู “สมัครสมาชิก”)
1. **ขั้นที่ 1 ยืนยันตัวตน** — ถ้ามีรหัสนักศึกษา เลือก “Claim ระเบียนเดิม” แล้วกรอกรหัสพร้อมวันเกิด *หรือ* เลขบัตรประชาชน 4 หลักท้าย (ระบบไม่เก็บเลขบัตรเต็ม) · ถ้าจำรหัสไม่ได้ เลือก “สมัครใหม่”
2. **ขั้นที่ 2 ชื่อและการศึกษา** — เลือกระดับและ**ชื่อสาขาตามที่ใช้ตอนเรียน** (เช่น ช่างยนต์) ระบบแสดงชื่อปัจจุบันให้เอง · ใส่ชื่อ-นามสกุลเดิมได้ เพื่อนจะค้นเจอแม้คุณเปลี่ยนชื่อแล้ว · ลากรูปมาวางเพื่ออัปโหลดได้
3. **ขั้นที่ 3 ติดต่อ** — ตั้งรหัสผ่าน (อย่างน้อย 10 ตัว มีทั้งตัวอักษรและตัวเลข) และเลือกว่าใครเห็นข้อมูลติดต่อ
4. **ขั้นที่ 4 ความยินยอม** — อ่าน[นโยบายความเป็นส่วนตัว](/privacy) แล้วเลือกยินยอม
5. เจ้าหน้าที่ตรวจและอนุมัติ โดยทั่วไปไม่เกิน 1–2 วันทำการ ระหว่างรอเข้าสู่ระบบและแก้โปรไฟล์ได้ แต่ยังส่งข่าว/ลงทะเบียนกิจกรรมไม่ได้

ถ้าขึ้นว่า “อีเมลนี้เคยใช้ส่งใบสมัครแล้ว” แปลว่าเคยสมัครด้วยอีเมลนี้ ให้ใช้ **ลืมรหัสผ่าน** เพื่อตั้งรหัสให้ใบสมัครเดิม

### นักศึกษาปัจจุบัน
หน้า “เข้าสู่ระบบ” → **สร้างบัญชีนักศึกษา** ด้วยรหัสนักศึกษา · ใช้ดูประกาศงาน/ฝึกงานพร้อมช่องทางสมัคร และรับแจ้งเตือนประกาศใหม่

### เข้าสู่ระบบ / ลืมรหัสผ่าน
เข้าสู่ระบบด้วยอีเมลและรหัสผ่าน (หรือ LINE ถ้าผูกบัญชีไว้) · ลืมรหัสผ่าน → กรอกอีเมล → เปิดลิงก์ในอีเมลภายใน 1 ชั่วโมง · กรอกผิด 5 ครั้งจะถูกระงับ 15 นาที

## 2. พื้นที่ของฉัน (ปุ่ม “ของฉัน” มุมขวาบน)

| เมนู | ทำอะไรได้ |
|---|---|
| ภาพรวม | ความสมบูรณ์ของโปรไฟล์และสิ่งที่ควรเติม · ปุ่ม **ข้อมูลยังถูกต้อง** (กดครั้งเดียวเมื่อไม่มีอะไรเปลี่ยน) |
| ชื่อและรูป | แก้ชื่อ (ชื่อเดิมถูกเก็บให้อัตโนมัติ) ชื่อเดิม และรูปโปรไฟล์ |
| การทำงานและทักษะ | ประวัติการทำงานหลายรายการ และทักษะ |
| ติดต่อและความเป็นส่วนตัว | อีเมล โทรศัพท์ LINE จังหวัด และเลือก**ทีละช่อง**ว่า สาธารณะ / เฉพาะสมาชิก / ไม่เปิดเผย · เปิดหรือปิดการแสดงในทำเนียบ |
| ข่าวของฉัน | ส่งข่าว ฉบับร่าง ดูผลการตรวจ · ข่าวที่มีคนแท็กคุณ และ **ปฏิเสธการแท็ก** |
| กิจกรรม งาน บทความ | กิจกรรมที่ลงทะเบียน ประกาศงาน บทความ และการเสนอชื่อของคุณ |
| แบบสำรวจ | ตอบแบบสำรวจภาวะการทำงาน และเชิญหัวหน้างานตอบแบบสำรวจผู้ใช้บัณฑิต |
| ข้อมูลของฉัน (PDPA) | ดาวน์โหลดข้อมูลทั้งหมดของคุณ และยื่นคำขอแก้ไข ลบ ถอนความยินยอม หรือคัดค้าน |
| การแจ้งเตือน | กล่องแจ้งเตือน และตั้งค่ารายประเภท: ในเว็บ / อีเมล / LINE และความถี่ ทันที / สรุปรายสัปดาห์ / ปิด |
| บัญชีและรหัสผ่าน | เปลี่ยนรหัสผ่าน ผูกหรือยกเลิก LINE |

## 3. ใช้งานเว็บไซต์

- **ทำเนียบศิษย์เก่า** — ค้นด้วยชื่อ ชื่อเดิม ชื่อเล่น หรือที่ทำงาน (สะกดผิดเล็กน้อยก็ค้นเจอ) และกรองหลายเงื่อนไขพร้อมกัน: รุ่น ระดับ สาขา จังหวัด กลุ่มอาชีพ ทักษะ · ข้อมูลติดต่อเห็นตามที่เจ้าของตั้งไว้ ผู้ที่ยังไม่เข้าสู่ระบบไม่เห็นข้อมูลติดต่อ
- **ข่าวศิษย์เก่า** — กรองตามประเภท รุ่น สาขา · กด 👏 แสดงความยินดี แสดงความคิดเห็น หรือ “รายงานเนื้อหาไม่เหมาะสม” (สมาชิกที่ยืนยันแล้วและนักศึกษา)
- **ส่งข่าว** — “ข่าวของฉัน” → ส่งข่าว: เลือกประเภท ใครเห็นได้ (สาธารณะ / เฉพาะสมาชิก / เฉพาะรุ่นเดียวกัน) แนบรูป และแท็กเพื่อน · ข่าวผ่านการตรวจก่อนเผยแพร่ · แก้ข่าวที่เผยแพร่แล้วจะกลับไปตรวจใหม่
- **กิจกรรม** — ดูปฏิทินรายเดือน ลงทะเบียนหรือยกเลิก จองของที่ระลึก (ชำระเงินและรับของตามที่คณะแจ้ง) · ระบบเตือนก่อนวันงาน
- **งานและฝึกงาน** — ค้นและกรองตามประเภท สาขา จังหวัด ทักษะ · ช่องทางสมัครแสดงเมื่อเข้าสู่ระบบ · ศิษย์เก่าประกาศงานได้ที่ “กิจกรรม งาน บทความ” (ตรวจก่อนเผยแพร่ หมดอายุตามวันปิดรับ ไม่เกิน 120 วัน)
- **คลังความรู้** — อ่านและค้นบทความตามหมวด · ศิษย์เก่าเขียนบทความแบ่งปันประสบการณ์ได้ (ตรวจก่อนเผยแพร่)
- **ศิษย์เก่าดีเด่น** — ดูทำเนียบ และ **เสนอชื่อ** เมื่อเปิดรอบ (ไม่เกิน 5 คนต่อรอบ แนบเอกสารได้)
- **ข่าวประชาสัมพันธ์ / แกลเลอรี** — ค้นข่าว กรองตามหมวดหรือแท็ก ดาวน์โหลดเอกสารแนบ และดูอัลบั้มภาพกิจกรรม

## 4. ความเป็นส่วนตัวโดยย่อ
- ข้อมูลของคุณแสดงในทำเนียบเฉพาะเมื่อยืนยันตัวตนแล้วและยินยอม
- ทุกครั้งที่มีคนเปิดดูโปรไฟล์ของคุณ ระบบบันทึกไว้
- รายได้ในแบบสำรวจเก็บเป็นช่วงและรายงานแบบรวมกลุ่มเท่านั้น
- ยกเลิกรับอีเมลได้จากลิงก์ท้ายอีเมลทุกฉบับ
- รายละเอียดทั้งหมด: [นโยบายความเป็นส่วนตัว](/privacy)
