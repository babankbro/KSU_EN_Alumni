# คู่มือผู้ดูแลระบบ — หลังบ้านระบบศิษย์เก่า

สำหรับเจ้าหน้าที่ (NFR-MNT-01) · เข้าใช้ที่ `/admin/login` หรือหน้า “เข้าสู่ระบบ” ปกติก็ได้ (ระบบพาเข้าหลังบ้านให้เมื่อเป็นบัญชีเจ้าหน้าที่)

## 1. บทบาทและสิทธิ์

| เมนู | ผู้ดูแลระบบ | ผู้แก้ไขเนื้อหา | อาจารย์/กรรมการ |
|---|:--:|:--:|:--:|
| ภาพรวม | ✓ | ✓ (ไม่เห็นตัวเลขสมาชิก) | ✓ |

ทุกครั้งที่เปิดดูข้อมูลสมาชิก ส่งออก ตัดสินเนื้อหา หรือแก้ข้อมูล ระบบบันทึกไว้ใน audit log พร้อมชื่อผู้ทำ

## 2. งานประจำวัน

### 2.1 อนุมัติสมาชิก (เมนู “สมาชิก”)
1. กดการ์ด **รอตรวจสอบ** เพื่อกรองเฉพาะใบสมัครค้าง
2. เปิดรายชื่อ ตรวจชื่อ รุ่น สาขา กับเอกสารทะเบียน (ถ้ามีข้อความ “ชื่อสาขานี้ยังไม่ได้ยืนยันกับงานทะเบียน” ให้ตรวจเป็นพิเศษ)
3. กด **อนุมัติเป็นสมาชิก** หรือ **ไม่อนุมัติ** พร้อมหมายเหตุ — ผู้สมัครได้รับแจ้งทางอีเมล
   - ไม่อนุมัติการ *claim* ระเบียนเดิม → ระเบียนกลับเป็น “ยังไม่ Claim” เจ้าของตัวจริงยัง claim ได้
   - ไม่อนุมัติการ *สมัครใหม่* → เก็บเป็น “ไม่อนุมัติ”
4. ปุ่ม **ส่งออก CSV** ส่งออกตามตัวกรองที่เลือกอยู่ (เปิดใน Excel ภาษาไทยได้)

### 2.2 ตรวจสอบเนื้อหา (เมนู “ตรวจสอบเนื้อหา”)
แท็บ: ข่าวศิษย์เก่ารอตรวจ · ประกาศงานรอตรวจ · บทความรอตรวจ · รายงานเนื้อหา · ข่าวที่เผยแพร่แล้ว — ตัวเลขข้างเมนูคือจำนวนที่ค้าง

- **อนุมัติ** เผยแพร่ทันที และแจ้งผู้ส่ง (ข่าวศิษย์เก่าจะแจ้งผู้ถูกแท็กและเพื่อนร่วมรุ่นด้วย)
- **ขอให้แก้ไข / ไม่อนุมัติ / ซ่อน / ลบ** ต้องเขียนเหตุผล ผู้ส่งเห็นข้อความนั้น
- **ข่าวไว้อาลัย** ต้องตรวจทุกครั้ง: ยืนยันข้อเท็จจริงกับครอบครัวหรือแหล่งที่เชื่อถือได้ แล้วติ๊ก “ตรวจสอบข้อเท็จจริงแล้ว” ก่อนอนุมัติ — การอนุมัติ**ไม่**เปลี่ยนสถานะระเบียนเป็นเสียชีวิตโดยอัตโนมัติ
- **ให้เผยแพร่ทันทีในครั้งต่อไป** (ผู้ดูแลระบบ) — ผู้โพสต์ที่มีประวัติดีข้ามการตรวจได้ ยกเว้นข่าวไว้อาลัย
- **รายงานเนื้อหา** รวมเป็นรายการเดียวต่อชิ้นงาน: “ซ่อนเนื้อหา” (ระบุเหตุผล) หรือ “ไม่พบการละเมิด — ปิดรายงาน”
- แท็บ **ข่าวที่เผยแพร่แล้ว** ใช้ปักหมุดข่าวเด่น ซ่อน หรือนำกลับมาแสดง

### 2.3 ข่าวประชาสัมพันธ์
สร้าง/แก้ข่าวพร้อมภาพปก หมวด **แท็ก** (คั่นด้วยจุลภาค) และเลือก ฉบับร่าง / เผยแพร่ทันที / ตั้งเวลา · ในหน้าแก้ไขข่าวมีส่วน **เอกสารแนบ (PDF)** · เนื้อหาเว้นบรรทัดว่างเพื่อขึ้นย่อหน้า (ไม่รองรับ HTML)

### 2.4 กิจกรรม
1. **สร้างกิจกรรม**: วันเวลา (เวลาไทย) สถานที่ จำนวนที่รับ วันปิดรับ ภาพปก และติ๊ก “เผยแพร่บนหน้าเว็บ”
2. หน้ากิจกรรมแต่ละรายการแสดง **ผู้ลงทะเบียน** พร้อมปุ่ม **ส่งออก CSV**
3. **ของที่ระลึก**: เพิ่มสินค้า ราคา จำนวน (เว้นว่าง = ไม่จำกัด) และตัวเลือก เช่น `S, M, L` · ปรับสถานะรายการจองเป็น ชำระแล้ว / รับของแล้ว (ระบบไม่รับชำระเงินเอง)
4. ระบบส่งแจ้งเตือนผู้ลงทะเบียนอัตโนมัติภายใน 36 ชั่วโมงก่อนเริ่มงาน

### 2.5 แกลเลอรี
สร้างอัลบั้ม (เชื่อมกับกิจกรรมได้) → อัปโหลดหลายรูปพร้อมกัน → ใส่คำบรรยาย → **เผยแพร่อัลบั้ม** · ภาพในแกลเลอรีเป็นสาธารณะ หลีกเลี่ยงภาพที่เห็นข้อมูลส่วนบุคคลชัดเจน

### 2.6 ข้อมูลและรูปภาพเว็บ
แก้ข้อความหน้าแรก สารจากคณบดี ข้อมูลติดต่อ ลิงก์โซเชียล และเปลี่ยนรูปหน้าแรก/คณบดี/ภาพปกข่าวเริ่มต้น (คืนค่าเริ่มต้นได้)

## 3. งานรายรอบ

### 3.1 ศิษย์เก่าดีเด่น
สร้างรอบ (วันเปิด–ปิด) → ศิษย์เก่าเสนอชื่อพร้อมเหตุผลและเอกสาร → กรรมการเปิดรอบ อ่าน และบันทึกผล: รอพิจารณา / ผ่านเข้ารอบ / **ได้รับรางวัล** (ต้องเขียนคำประกาศเกียรติคุณ — แสดงบนเว็บ) / ไม่ได้รับเลือก · เอกสารประกอบเห็นเฉพาะเจ้าหน้าที่

### 3.2 แบบสำรวจ (ภาวะการมีงานทำ / ผู้ใช้บัณฑิต)
1. **สร้างรอบใหม่** โดยคัดลอกคำถามจากรอบก่อน เพื่อให้เทียบข้อมูลข้ามปีได้ → สถานะเริ่มเป็นฉบับร่าง → กด **เปิดรับคำตอบ**
2. บัณฑิตตอบที่หน้า “แบบสำรวจ” ของตน และเชิญหัวหน้างานผ่านลิงก์อีเมลใช้ครั้งเดียว (30 วัน)
3. Dashboard กรองตามสาขาและปีที่จบ แสดงภาวะการมีงานทำแยกสาขาและตามจำนวนปีหลังจบ · **ส่งออกรายงาน CSV** สำหรับเอกสาร QA
4. กลุ่มที่มีผู้ตอบน้อยกว่า 5 คนจะไม่แสดงสัดส่วน และรายได้แสดงเป็นช่วงเท่านั้น — เป็นการปกป้องผู้ตอบ ไม่ใช่ข้อผิดพลาด

### 3.3 ส่งประกาศ และรอบยืนยันข้อมูล (ผู้ดูแลระบบ)
- เลือกกลุ่ม (ศิษย์เก่า/นักศึกษา รุ่น สาขา ระดับ) → **นับผู้รับ** → เขียนข้อความ → ติ๊กยืนยัน → ส่ง · ผู้รับได้ตามช่องทางที่แต่ละคนตั้งไว้
- **รอบยืนยันข้อมูล** ส่งคำเชิญถึงคนที่ไม่ได้อัปเดตนานเกินกำหนด (ค่าเริ่มต้น 12 เดือน) แนะนำปีละ 1 ครั้ง

## 4. ข้อมูลส่วนบุคคลและข้อมูลหลัก (ผู้ดูแลระบบ)

### 4.1 คำขอ PDPA
ต้องตอบภายใน 30 วัน (ตัวเลขวันแสดงสีแดงเมื่อใกล้ครบ) · เลือก เสร็จสิ้น / กำลังดำเนินการ / ปฏิเสธ (ต้องระบุเหตุผล) — ผู้ร้องขอได้รับแจ้งทุกครั้ง
- **ขอลบข้อมูล**: ติ๊ก “ลบข้อมูลส่วนบุคคลถาวร” และพิมพ์ `ลบข้อมูล` → ระบบส่งอีเมลแจ้งก่อน แล้วลบชื่อ ติดต่อ ประวัติงาน ข่าว บทความ ความคิดเห็น การลงทะเบียน ไฟล์ และปิดบัญชี เหลือเฉพาะสาขาและปีสำหรับสถิติ **ย้อนกลับไม่ได้**
- ขอสำเนาข้อมูล: เจ้าของดาวน์โหลดเองได้ทันที ใช้คำขอนี้เมื่อต้องการเอกสารรับรอง

### 4.2 นำเข้าข้อมูล
ดาวน์โหลด **ไฟล์ตัวอย่าง** → เติมข้อมูลจากทะเบียน (UTF-8, ไม่เกิน 5,000 แถว) → อัปโหลด · ระบบรายงานแถวที่ผิดพร้อมเลขบรรทัด รหัสนักศึกษาที่มีอยู่แล้วจะถูกข้าม ไม่เขียนทับ · ระเบียนที่นำเข้าเป็น “ยังไม่ Claim” ไม่แสดงในทำเนียบจนเจ้าของยืนยันตัวตน

### 4.3 ระเบียนซ้ำ
ระบบเสนอคู่ที่สาขาเดียวกัน รุ่นห่างไม่เกิน 1 ปี และชื่อใกล้เคียง → เปิดดูทั้งสองระเบียน → เลือก **ระเบียนที่จะเก็บ** → ติ๊กยืนยัน → รวม · ชื่อของระเบียนที่ถูกรวมกลายเป็นชื่อเดิม และมีสำเนาเก็บไว้

### 4.4 ข้อมูลอ้างอิง
- **หลักสูตร**: แก้ชื่อ สถานะ (เปิดสอน/เปลี่ยนชื่อแล้ว/ปิดแล้ว) และ “หลักสูตรสืบทอด” เมื่อสาขาเปลี่ยนชื่อ — สถิติและการค้นหาจะรวมชื่อเดิมเข้ากับชื่อใหม่ ห้ามลบหลักสูตรที่มีศิษย์เก่า
- **ทักษะ**: ตั้งชื่อซ้ำกับทักษะที่มีอยู่ = รวมสองทักษะ · ลบได้เฉพาะที่ไม่มีใครใช้
- **กลุ่มอาชีพ**: เปลี่ยนชื่อแล้วประวัติการทำงานเดิมเปลี่ยนตาม

### 4.5 บัญชีเจ้าหน้าที่
สร้างบัญชี (รหัสชั่วคราว ≥ 12 ตัว แจ้งเจ้าของทางช่องทางที่ปลอดภัย) · เปลี่ยนบทบาท (มีผลเมื่อเข้าสู่ระบบครั้งถัดไป) · ปิดบัญชีเมื่อพ้นหน้าที่ · ตั้งรหัสใหม่ · ระบบไม่ยอมให้เหลือผู้ดูแลระบบน้อยกว่า 1 คน และไม่ให้ปิดบัญชีตนเอง

## 5. ข้อควรปฏิบัติ

- ออกจากระบบเมื่อใช้เครื่องร่วมกับผู้อื่น (session หลังบ้านหมดอายุเองใน 8 ชั่วโมง)
